# /brag-slim plan: NAB Quality Loop

**Input:** project `nab-quality-loop` (Vite + React). The video reuses its real `styles.css`, `content.js`, brand assets and component markup (hero loop ring, 6-stage quality loop pipeline, TestKraft prompt/returns pad, NeoDataTest mini-pipe, 4-gate Eval Harness verdict). Everything is rendered frame by frame as a pure function of time.
**Format:** landscape 1920x1080, 30 fps, 22.4 s. **Tone:** `polished` (serious, elegant, restrained, for a regulated bank).

## Answers
- **What is it?** StatusNeo's agentic Quality Engineering accelerators, set up as one governed loop: Enterprise Brain blast radius, TestKraft generation, Agent CI/CD, a 4-gate Eval Harness, and NeoDataTest for data pipelines.
- **Who is it for?** NAB's Quality Engineering / QA leadership. Every change gets tested by impact and every release is proven with evidence.
- **What sets it apart?** Governance runs as code: "No production release without domain scenarios, trace-level evidence, and explicit threshold gates." It sits on top of existing test packs with no rewrite.
- **Most impressive claim:** "Describe a test. Get a tested pull request." (TestKraft: 90%+ predictable coverage, 20–30% faster release velocity, 25–30% fewer escaped defects, no rewrite of existing test packs).
- **Visual hook:** the big Inter Tight / Instrument Serif headline "Quality, engineered / as a governed loop." next to the spinning Authentic AI loop ring, under a NAB × StatusNeo lockup.
- **Real flow shown:** one CDR / Open Banking change goes through the pipeline (Ingest → Blast radius → Generate → CI → Gate PASSED), then TestKraft types the CDR API prompt and returns its outputs, then the four gates light to PASSED.
- **Share caption:** see share-copy.txt.

## Angle
Quality is shown as one loop the viewer can watch run: a single bank change enters, gets tested by impact, and leaves with evidence. It is presented as a governed system, not as a set of tools.

## Hook (0–3.5 s)
The NAB × StatusNeo lockup, then "Quality, engineered" rises line by line into "*as a governed loop.*" while the Authentic AI Loop ring spins. The site's "Prepared for" card is left out, and no personal names appear anywhere.

## Highlights
1. **The loop, in use.** The cursor picks "CDR / Open Banking API version bump" and the six-stage pipeline lights one stage at a time. Each stage's headline stacks into a log. This is labelled "Illustrative walkthrough" exactly as it is on the site.
2. **TestKraft.** "Describe a test. Get a tested pull request." The CDR API prompt types itself, then the returns tick in. Published outcomes (90%+, 20–30%, 25–30%, 0 rewrites) and the NeoDataTest card ("Trust your data pipelines.") sit alongside.
3. **Governance.** "No production release without domain scenarios, trace-level evidence, and explicit threshold gates." Gates 01–04 light up and the verdict turns to PASSED ("evidence pack stored").

## Punchline / outro
"Ready to see it, *not hear about it?*" with the accelerator names, the playground.statusneo.com call to action, and the StatusNeo and Authentic AI logos.
